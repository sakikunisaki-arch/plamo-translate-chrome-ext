# PLaMo Translate (LM Studio) — Chrome 拡張機能

ローカルで稼働する **LM Studio** 上の **`plamo-3-translate-2b`** モデルを使って、英語から日本語への翻訳をブラウザ上で完結させる Chrome 拡張機能（Manifest V3）です。外部 API にテキストを送信せず、プライバシーを保ったまま高速に翻訳できます。

## 主な機能

1. **サイドパネル翻訳（ストリーミング対応）**
   - 自由入力した英文をリアルタイムのストリーミング表示で日本語に翻訳
   - 文体切り替え：**敬体（です・ます調 / `form=polite`）** と **常体（だ・である調 / `form=plain`）**
   - Web ページ上の選択テキストを取り込んで即座に翻訳（ボタンまたは右クリックメニューから）
   - 翻訳履歴（最新 10 件）の保存・ワンクリック復元・削除
2. **ページ全体の一括翻訳**
   - 現在のページ内の英語ブロックを自動抽出し、表示中の画面（ビューポート）に近い箇所から優先翻訳
   - 既に日本語のブロックやコードブロック（`<code>`, `<pre>` 等）は自動スキップ
   - 表示モード切替：**原文＋訳文（併記）** / **訳文のみ（置換）** / **原文に戻す**（非破壊復元）
   - 右下のフローティングミニバーから進行状況確認・モード切替・中止・復元が可能
3. **用語集（Glossary）とカスタマイズ**
   - 設定タブから `英語 => 日本語` 形式でカスタム用語集を指定可能
   - 並列リクエスト数（1〜4）、LM Studio URL・モデル名の切り替えに対応

## 事前準備：LM Studio の起動と CORS 設定

1. **LM Studio** を起動し、モデル **`plamo-3-translate-2b`** をロードします。
2. 左側の **Developer**（開発者）タブを開きます。
3. **Server Settings** から以下を確認してください：
   - **Port**: `1234`（既定値）
   - **Enable CORS**: **ON** を推奨（通常は Background Service Worker 経由で接続しますが、環境や LM Studio バージョンによって `403` 等が出る場合は Enable CORS を ON にしてください）
4. Local Server の **Status** を **Running** にします。
   - CLI の場合: `lms server start --port 1234 --cors`

## Chrome へのインストール手順（デベロッパーモード）

1. Google Chrome で `chrome://extensions/` を開きます。
2. 右上の **デベロッパー モード**（Developer mode）を **ON** にします。
3. 左上の **パッケージ化されていない拡張機能を読み込む**（Load unpacked）をクリックします。
4. 本ディレクトリ（`plamo-translate-chrome-ext`）を選択します。
5. ツールバーの拡張機能アイコンから **PLaMo Translate** をピン留めしておくと便利です。

## 使い方

### サイドパネルで翻訳する
- ツールバーの **PLaMo Translate** アイコンをクリックするとサイドパネルが開きます。
- 英文を入力し、**「翻訳する」**（または `Cmd+Enter` / `Ctrl+Enter`）を押すと翻訳結果がストリーミング表示されます。
- Web ページ上の英文を選択して右クリック → **「PLaMoで選択テキストを翻訳（サイドパネル）」** を選ぶと、選択テキストを自動で取り込んで翻訳します。

### ページ全体を翻訳する
- サイドパネルの **「ページ翻訳」** タブから **「ページ全体を翻訳」** をクリックします（またはページ上で右クリック → **「PLaMoでページ全体を翻訳」**）。
- 翻訳中でも、**「原文＋訳文（併記）」** と **「訳文のみ（置換）」** を切り替えたり、**「翻訳を中止」** や **「原文に戻す」** を実行できます。
- ※ `chrome://` ページや Chrome ウェブストアなど、ブラウザの制限されたページでは動作しません。

### 用語集・接続設定を変更する
- サイドパネルの **「設定」** タブで LM Studio URL、モデル名、既定の文体、並列数、用語集を編集し、**「設定を保存」** を押してください。
- 用語集の記述例：
  ```text
  dashboard => 管理画面
  invoice => 請求書
  ```

## テストの実行方法

プロジェクトの整合性チェック（静的テスト）：
```bash
python3 tests/test_extension.py
```

LM Studio 実機（`http://localhost:1234`）との疎通・翻訳・ストリーミング確認：
```bash
python3 tests/test_extension.py --live-lmstudio
```
